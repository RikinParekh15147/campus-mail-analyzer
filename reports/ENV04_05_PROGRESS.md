# Portable launch and verification — 28 October 2026

The desktop backend command now selects the macOS/Linux or Windows isolated Python path through one tested function, while packaged mode selects the matching frozen executable. Startup checks the expected Campus Mail health response, exits promptly on spawn or process failure, has a bounded probe, and terminates the child on failure. Quit waits briefly for the Python child and force-stops a stalled child. A setup regression checks that a missing native Python command fails before installation; the Windows branch is ready for the CI runner.

`scripts/verify_portable.py` runs exact-version imports, doctor, the portable Python suite, desktop bridge tests, frontend build, and optionally the real Electron/Python workflow. It writes a run directory with individual logs and a JSON summary containing machine, source commit, dirty-tree status, Python/numerical versions, and hashes of the Python constraints and desktop lock. The Mac/Windows CI matrix now runs this same command after setup and `npm ci`, uploading the evidence even if a check fails.
